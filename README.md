# ESPADANA INVOICE SYS

نسخه تحت وب و قابل نصب (PWA) سامانه صدور پیش‌فاکتور اسپادانا.

## قابلیت‌ها

- ثبت شماره موبایل اقدام‌کننده در اولین اجرا
- ورود با رمز ثابت و نشست امن سمت سرور
- شماره‌گذاری سراسری و اتمیک فاکتورها بین همه کاربران
- ذخیره و جست‌وجوی مشتریان با نام یا شناسه ملی
- تکمیل خودکار اطلاعات مشتری با امکان ویرایش
- شرایط حمل و اعتبار قابل ویرایش برای هر فاکتور
- ذخیره امن اطلاعات در PostgreSQL/Neon از طریق API سمت سرور

## اجرای محلی

1. فایل `.env.example` را به `.env` کپی و `DATABASE_URL` و `APP_PASSWORD` را تنظیم کنید.
2. `npm install` را اجرا کنید.
3. schema موجود در `db/schema.sql` را روی PostgreSQL اجرا کنید.
4. برای توسعه محلی، پروژه را با محیط سازگار با Vercel Functions اجرا کنید.

رمز ورود فقط باید در متغیر محرمانه `APP_PASSWORD` قرار گیرد. هیچ رمز، کلید دیتابیس، فایل امضای Android یا فایل `.env` نباید commit شود.
